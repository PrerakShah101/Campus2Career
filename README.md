# Campus2Career AI 🎓

> **Your next career move, made clearer.**  
> A friendly, student-focused career roadmap application that analyzes real-world job posting expectations, identifies your personal skill gaps, and generates an actionable four-week learning plan and portfolio project recommendations.

---

## 🌸 Visual Identity & Design Philosophy

Campus2Career AI avoids cold enterprise dashboards, neon AI gimmicks, and generic chat interfaces. It is crafted with a **pastel, playful, modern** aesthetic inspired by modern study planners, bullet journals, stationery, and Notion-style simplicity.

- **Warm Off-White Background:** `#FFFCF7`
- **Soft Lavender:** `#E9E2FF` (Core interactive accents & badges)
- **Pastel Mint:** `#DDF3E4` (Matched skills & progress indicators)
- **Pale Peach:** `#FFE4D6` (Portfolio badges & project tags)
- **Butter Yellow:** `#FFF1B8` (Milestones & highlights)
- **Muted Dark Typography:** `#343344` using clean sans-serif fonts (`DM Sans` and `Inter`)
- **Card Styling:** 18px–20px rounded corner radii, subtle 1px border lines, comfortable spacing, and soft hover feedback.

## 🚀 Key Features

1. **Target Role Selection:** Choose between 4 high-demand student career tracks:
   - *Machine Learning Intern*
   - *Data Scientist*
   - *Data Analyst*
   - *Software Engineer*
2. **Current Skills Inventory:** Select what you know across Programming, Data, AI/ML, and Development, or select *"None yet, I'm starting fresh"*.
3. **Paced Study Planning:** Choose your weekly study commitment (default 6 hours/week) to scale the workload realistically.
4. **Transparent Skill Coverage Metric:** A clear percentage showing how many core employer requirements match your current toolkit, paired with an explicit explanation of how it is calculated.
5. **Empirical Employer Demand Chart:** A pastel horizontal bar chart displaying skill frequencies observed in sample job postings, with sample counts clearly labeled as sample observations.
6. **Two-Tier Gap Analysis:**
   - 🌿 *Already on your list* (pastel mint)
   - 💜 *Worth learning next* (pastel lavender)
   *(Accompanied by an honest disclaimer that listed skills indicate coursework familiarity, not proof of workplace proficiency).*
7. **Personalized 4-Week Roadmap:** Weekly titles, learning objectives, practical tasks, and clear completion outcomes.
8. **Real Portfolio Projects:** Two concrete, achievable project recommendations tailored to your missing skills with small first milestones.

### 1. Gemma LLM Integration & Transparent Fallback
- **Endpoint Protocol:** Uses Google's official Gemini API `generateContent` endpoint through `requests`. Configure `GOOGLE_API_KEY` and `GEMMA_MODEL` in `.env`. The default hosted model is `gemma-4-26b-a4b-it`; access and quota depend on your Google AI Studio project.
- **Validation Before Claim:** The app sends one generation request per analysis and only labels results AI-generated after validating the returned JSON.
- **Strict Structured JSON:** Prompts Gemma for structured JSON matching the roadmap and portfolio project schema.
- **Honest Attribution:** If Gemma is not configured or offline, Campus2Career seamlessly executes a deterministic, pedagogical **Rule-Based Guidance Engine** and explicitly badges results as *"Curated Rule-Based Guidance"*—it never falsely claims fallback output was generated by Gemma.

### 2. Multi-Tier Skill Matching
- **Tier 1:** Exact canonical string match.
- **Tier 2:** Domain-specific alias dictionary (e.g., `sklearn` ↔ `Scikit-learn`, `dsa` ↔ `Data Structures and Algorithms`, `postgres` ↔ `SQL`, `neural networks` ↔ `Deep Learning`).
- **Tier 3:** Character n-gram TF-IDF cosine similarity from `scikit-learn`; optional `sentence-transformers/all-MiniLM-L6-v2` neural embeddings can be enabled with `USE_SEMANTIC_EMBEDDINGS=true` after installing `sentence-transformers`.
- **Configurable Threshold:** Defaults to `0.68`, adjustable via the Settings popover. The lightweight exact/TF-IDF matcher works without downloading a neural embedding model.

## 📊 Dataset Acquisition, Preprocessing & Limitations

- **Primary Source:** [`MichaelYitzchak/LinkedInJobPostings`](https://huggingface.co/datasets/MichaelYitzchak/LinkedInJobPostings) on Hugging Face.
- **License:** See the dataset card for the source dataset's current license and usage conditions. The local metadata records the source's reported license; verify it before redistribution.
- **Filtering Pipeline:**
  1. Streamed programmatically using the Hugging Face `datasets` library to avoid downloading gigabytes of unneeded raw data.
  2. Filtered against regex role patterns for *Machine Learning Intern*, *Data Scientist*, *Data Analyst*, and *Software Engineer*.
  3. Deduplicated on `(job_title, company)` and cleaned of missing descriptions or low-signal rows.
  4. Extracted and normalized skills from job text using predefined skill vocabularies and alias mapping.
  5. Cached locally to `data/jobs.csv` with standard columns: `job_title`, `target_role`, `company`, `description`, `skills`, `location`.
- **Limitations:**
  - Postings represent a historical sample of LinkedIn listings and do not constitute an exhaustive or live market census.
  - Frequency percentages reflect mentions in this sample pool, not definitive job market statistics.

## 🛠️ Installation & Windows Setup

### Prerequisites
- Python 3.10+ (Tested on Python 3.13)
- Windows PowerShell or Command Prompt

### Step-by-Step Commands

```powershell
# 1. Clone or navigate to the project directory
cd "c:\Users\Prerak Shah\OneDrive\Desktop\Campus2Career"

# 2. Install dependencies
python -m pip install -r requirements.txt

# 3. (Optional) Configure Google AI Studio Gemma
Copy-Item .env.example .env
# Edit .env and set GOOGLE_API_KEY
# Create a key at https://aistudio.google.com/apikey

# 4. (Optional) Refresh/download the source dataset
# This step needs internet access and the optional datasets package.
# python -m pip install datasets
# python scripts/preprocess_jobs.py

# 5. Run unit tests
python -m pytest tests/ -v

# 6. Launch the Streamlit web application
python -m streamlit run app.py
```

The application will launch at: **`http://localhost:8501`**

### Optional semantic embedding model

The app works without downloading a neural embedding model. If you want the optional Sentence Transformers matcher, install it separately with `python -m pip install sentence-transformers`. This may download PyTorch and model weights, so skip it for a time-constrained demo if the environment is not ready.

## 🔬 Graphify OSS Codebase Analysis

Graphify OSS (`graphifyy`) was run to analyze the Campus2Career source repository and extract code relationships via local Abstract Syntax Tree (AST) parsing:

```powershell
# Run local AST extraction
python -m graphify extract . --code-only

# Generate interactive HTML architecture map
python -m graphify export html
```

Run these commands from the project root after installing Graphify OSS. The checked-in graph files are a previous snapshot and may not include the latest repairs.

- **Graph Structure:** `graphify-out/graph.json` contains the generated code relationship graph. Because the source code has since been repaired, regenerate this snapshot before presenting it.
- **Visual Exploration:** Open `graphify-out/graph.html` in any browser to inspect the saved module and function relationships.
- **Architectural Flow:**
  - `app.py` acts as the presentation orchestrator.
  - `src/data_loader.py` coordinates data ingestion and empirical frequency calculations.
  - `src/skill_matcher.py` encapsulates matching logic and vector similarity.
  - `src/llm_service.py` handles API communication, validation, and pedagogical fallback generation.
  - `src/analytics.py` decouples Plotly visualization formatting from business logic.

## Security and runtime notes

- Never commit `.env` or paste real API tokens into issue reports. The app's Settings popover keeps entered credentials in session state only and does not write them to disk.
- `.env.example` contains placeholders only. Copy it to `.env` locally if you prefer environment-based configuration.
- The default inference configuration uses Google AI Studio's official `generateContent` API with `gemma-4-26b-a4b-it`. Access and quota depend on your Google AI Studio project and model availability.
- Dataset counts are sample observations. They are not live job-market statistics and should not be generalized beyond the filtered dataset.
